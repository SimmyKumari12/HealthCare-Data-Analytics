# Healthcare Data Analytics & Executive Dashboard

## Overview

This project analyzes healthcare data to identify important trends and business insights related to patients, medical conditions, departments, billing, insurance, and hospital performance.

The analysis results are presented through a professional interactive dashboard designed to provide hospital management with a clear view of key KPIs, trends, and actionable insights.

## Key Features

* Patient and admission analysis
* Billing and revenue analysis
* Insurance analysis
* Department and medical condition insights
* Gender and demographic analysis
* Interactive filters and visualizations
* Executive-level KPIs and business insights
* Management-focused recommendations

## Technologies

* Python
* Pandas
* NumPy
* Matplotlib / Seaborn
* Jupyter Notebook
* HTML, CSS & JavaScript
* Interactive data visualization

## Project Output

The final output is a self-contained HTML executive dashboard containing:

* KPI cards
* Interactive charts
* Business insights
* Ad-hoc insights
* Management takeaways
* Dynamic filtering

## Objective

To transform healthcare data into meaningful business insights that can support data-driven decision-making and help hospital management understand operational and financial performance.
